#### 一、什么是布隆过滤器？
布隆过滤器（Bloom Filter）是一种空间效率非常高的概率型数据结构，用于判断一个元素是否属于一个集合。
#### 二、特点
    1、高效：查询和插入的时间复杂度为 O(k)，其中 k 是哈希函数的数量（调用次数）。
    2、节省内存：比哈希表或集合占用更少的空间。
    3、允许误判：可能会误判一个元素“存在”（假阳性），但绝不会误判一个元素“不存在”（没有假阴性）。
    4、不可删除元素（普通布隆过滤器）：一旦元素加入，无法删除，除非使用可计数布隆过滤器（Counting Bloom Filter）。

#### 三、原理
    1、初始化一个长度为 m 的位数组，全为 0。
    2、选择 k 个独立的哈希函数。
    3、插入元素：
        将元素通过每个哈希函数计算出位置 hi(x)，将对应位数组位置置 1。
    4、查询元素：
        通过哈希函数计算出位置，如果所有对应位都是 1，则认为元素可能存在；如果有任何一个是 0，则元素肯定不存在。

#### 四、python实现
```python
import hashlib

class BloomFilter:
    def __init__(self, size, hash_count):
        self.size = size  # 位数组长度
        self.hash_count = hash_count  # 哈希函数个数
        self.bit_array = [0] * size

    def _hashes(self, item):
        # 使用不同的哈希函数，这里用 hashlib 的 md5 和 sha1 的组合来模拟
        result = []
        for i in range(self.hash_count):
            hash_input = f"{item}-{i}".encode('utf-8')
            digest = hashlib.md5(hash_input).hexdigest()
            pos = int(digest, 16) % self.size
            result.append(pos)
        print("result",result)
        return result

    def add(self, item):
        print(item)
        print("_hashes",self._hashes(item))
        for pos in self._hashes(item):
            self.bit_array[pos] = 1

    def check(self, item):
        return all(self.bit_array[pos] for pos in self._hashes(item))

# 使用示例
bf = BloomFilter(size=500, hash_count=7)
bf.add("apple")
bf.add("banana")
'''
    item apple
    result [317, 192, 184, 110, 166, 55, 203]
    _hashes [317, 192, 184, 110, 166, 55, 203]
    result [317, 192, 184, 110, 166, 55, 203]
'''
print(bf.check("apple"))   # True（一定存在）
print(bf.check("cherry"))  # False 或 True（False表示不存在，True可能是假阳性）
```
    Python 实现的设计理念
    位数组代替集合：降低空间复杂度。
    多个哈希函数：增加分布均匀性，减少假阳性概率。
    可扩展性：增加位数组长度 m 或哈希函数数量 k 可以控制误判率。
    概率性结果：适合大数据过滤，例如 URL 去重、垃圾邮件检测、缓存存在性检查。


#### 五、理解和补充
    1、复杂度为 O(k)
